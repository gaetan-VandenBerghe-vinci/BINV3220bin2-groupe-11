Pipeline npm de validation

La commande npm run check enchaîne Oxlint, les vérifications TypeScript, les tests Vitest et les builds backend/frontend.

Exemple de règle testée : constraints.test.ts vérifie que SQLite refuse une offre avec un statut inconnu ou un titre vide.

Guide de processus et vérification manuelle

Modèle de pull request

.github/pull_request_template.md fournit une checklist destinée à la personne qui prépare ou révise une PR. Il demande, entre autres, de vérifier que npm run check passe, que les cas d’erreur sont testés et que l’application a été essayée dans le navigateur avec les profils concernés.

Exemple : cocher « Testé dans le navigateur, avec les profils concernés ». Checklist consultée; test navigateur non effectué pendant la séance

C’est une consigne de processus interprétée par un humain, et non une case artificiellement classée comme guide IA ou senseur computationnel.
